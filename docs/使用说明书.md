# 多瑞吉医学名家讲堂 · 使用说明书

本文面向拿到这套源码、想把它跑起来并实际操作一遍的**使用者**（不一定是开发者）。开发者看 `README.md` 即可，这里更侧重"怎么用"。

## 一、这是什么系统

一套浏览器访问的 B 端 + C 端平台：

- **前台（给普通用户/学员）**：浏览医学名家讲座、查看专家资料、观看讲座录播视频、用二维码分享视频。
- **后台（给管理员）**：维护专家、讲座、视频、用户等数据，并对内容进行上下线和上传管理。

技术栈：PHP 8 + Laravel 8，前端为 Bootstrap 5，数据库 MySQL。纯 Web，无需安装任何客户端。

---

## 二、把系统跑起来（一次性配置）

> 需要本机已装：PHP（≥7.4）、Composer、MySQL。Windows 下建议 PHP 开启 `pdo_mysql`、`gd`、`fileinfo`、`mbstring`、`openssl` 扩展（没开经常会遇到"图片不显示"或"启动失败"，这也是本项目踩过的坑）。

```bash
# 1. 安装 PHP 依赖（第一次）
composer install

# 2. 生成环境配置，并填入你自己的数据库账号密码
copy .env.example .env

# 3. 生成应用密钥
php artisan key:generate

# 4. 创建数据库（推荐库名 duoruiji），导入表结构并填充演示数据
php artisan migrate --seed

# 5. 让图片/视频能通过网址访问（这步不做，页面里图片是空白的）
php artisan storage:link

# 6. 启动服务
php artisan serve
```

启动后访问：

| 入口 | 地址 |
|------|------|
| 前台首页 | http://127.0.0.1:8000 |
| 后台管理 | http://127.0.0.1:8000/admin |

> 演示用的专家头像、讲座封面、示例视频已随源码一起提供（在 `storage/app/public/`），所以第 5 步做完，页面图片和视频就能正常显示，无需额外下载。

## 四、前台怎么用（普通用户）

1. **首页**：展示平台介绍、推荐讲座、名医专家。
2. **讲座列表**（`/lectures`）：可按关键词搜索、按分类筛选；点进详情看讲座简介和直播入口。
3. **专家列表**（`/experts`）：浏览专家名片，点进详情看学术介绍。
4. **视频列表**（`/videos`）：查看讲座录播视频，点开即可在线播放。
5. **视频二维码分享**：在视频详情页可生成专属二维码，扫码即可传播该视频。

## 五、后台怎么用（管理员）

用 `admin@test.com / 123456` 登录后访问 `/admin`：

1. **数据看台**：顶部分块展示专家/讲座/视频/用户等数量概况。
2. **专家管理**：新增、编辑、删除专家；上传专家头像；设置专家简介。
3. **讲座管理**：创建讲座、填写封面和内容、控制上架状态。
4. **视频管理**：维护视频标题、封面、绑定视频文件路径；支持富文本编辑（图文混排）。
5. **用户管理**：查看和编辑注册用户，可修改状态或身份标记。

操作规律：列表页有"新建"按钮 → 表单页填写后保存 → 列表出现记录 → 行尾可用"编辑/删除"。大多数界面与常见的后台 CRUD 一致，照着直觉点即可。

## 六、常见问题

**Q1：页面图片全是空白？**
先确认是否执行了 `php artisan storage:link`。它是把存储目录的软链接创建到可访问路径，没做这一步前端就会 404。

**Q2：`php artisan serve` 起不来 / 提示 php 不是内部命令？**
Windows 下：把 PHP 目录加进系统 PATH，并确认 php.ini 已开启 `pdo_mysql`、`openssl` 等扩展；改完 PATH 要重开终端才生效。

**Q3：端口被占用？**
`php artisan serve` 默认 8000，被占用会自动往后找端口。也可指定：`php artisan serve --port=8080`。

**Q4：数据库连不上？**
打开 `.env`，核对 `DB_HOST`、`DB_PORT`、`DB_DATABASE`、`DB_USERNAME`、`DB_PASSWORD` 是否和你本机 MySQL 一致，并确认该库已创建。

**Q5：我想重新造一批占位图片？**
可运行 `php artisan seed:test-media`（联网生成并写入图片；视频会从仓库内置的示例源复制）。一般不需要，默认数据已足够演示。
